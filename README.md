### 🧑‍💻 About Me

I'm a **Java Backend Engineer** focused on building **secure, maintainable, and scalable backend systems** with **Java 21** and **Spring Boot**. I enjoy designing REST APIs, organizing business logic around clear service boundaries, and making distributed applications more reliable through thoughtful security, data, and messaging design.

---

### 🏗️ Engineering Focus

- 🔐 **Security:** Keycloak, OAuth 2.0 / OpenID Connect, JWT validation, scope-based authorization, and service-to-service client credentials.
- 📨 **Reliable messaging:** RabbitMQ, transactional outbox pattern, publisher confirms, idempotent consumers, and dead-letter queues.
- 🛡️ **Resilient services:** Circuit breakers and retries with Resilience4j, plus synchronous service calls using Spring RestClient.
- 🔎 **Observability:** Spring Boot Actuator, SLF4J, MDC, and correlation ID propagation across HTTP and AMQP.
- 🧪 **Confidence in changes:** Unit and integration testing with JUnit 5, Mockito, MockMvc, and Testcontainers.
